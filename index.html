💻 Configuration requise

Système d'exploitation

  • Windows 10/11
  • macOS 10.15+
  • Linux (Ubuntu 20.04+)

Matériel

  • Processeur : Intel Core i3 / AMD Ryzen 3+
  • RAM : 4 Go minimum (8 Go recommandé)
  • Webcam compatible
  • Espace disque : 500 Mo

Logiciels requis

  • Python 3.8 ou supérieur
  • OpenCV
  • PyQt5
  • NumPy

📖 Installation

# 1. Clonez le dépôt
git clone https://github.com/votre-repo/studio-photo-fond-vert.git
cd studio-photo-fond-vert

# 2. Créez un environnement virtuel (recommandé)
python -m venv venv
source venv/bin/activate  # Sur Windows : venv\Scripts\activate

# 3. Installez les dépendances
pip install -r requirements.txt

# 4. Lancez l'application
python main.py
# Contenu du fichier requirements.txt
PyQt5==5.15.9
opencv-python==4.8.1.78
numpy==1.24.3

⚠️ Note : Assurez-vous d'avoir une webcam fonctionnelle et un fond vert correctement éclairé pour des résultats optimaux.

🎯 Guide d'utilisation

1️⃣ Configuration de la caméra

Sélectionnez votre webcam et cliquez sur "Démarrer" pour lancer la prévisualisation

2️⃣ Ajustement du détourage

Modifiez les paramètres de teinte, saturation, érosion et lissage pour un détourage parfait

3️⃣ Sélection du set

Choisissez parmi 4 sets différents avec des fonds et premiers plans variés

4️⃣ Positionnement

Ajustez la position de la personne avec les sliders X et Y

5️⃣ Capture

Saisissez le nom et l'email, puis cliquez sur "PRENDRE LA VUE" pour sauvegarder

6️⃣ Export

Les photos sont automatiquement sauvegardées dans le dossier "photos_sauvegardees"

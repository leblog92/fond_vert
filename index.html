Studio Photo
Fond Vert

Application Python de montage photo en temps réel — placez les visiteurs dans les décors illustrés du salon, avec détourage fond vert automatique.

⬇ Télécharger sur GitHub 📖 Documentation 🚀 Releases
1 🟩

Détourage en temps réel

Masque HSV ajustable (teinte, saturation, luminance, érosion, dilatation, lissage) avec aperçu caméra instantané.

2 🖼️

4 sets de décors

Fond, premier plan et zone de positionnement configurés précisément pour chaque décor illustré du salon.

3 🎚️

Correcteurs X / Y / Z

Positionnement et zoom de la personne dans la zone de composition. Plage ±500 px, zoom de 50 % à 200 %.

4 ⚡

Double résolution

Fichiers UI 600 px en cache pour la prévisualisation fluide, fichiers originaux 2000 px pour le montage sauvegardé.

5 💾

Sauvegarde JPEG + EXIF

Nom de fichier horodaté, métadonnées EXIF (nom, email, date, set), fichier texte associé. Qualité 85.

6 🖥️

Interface PyQt5

Interface trois panneaux — caméra, aperçu montage, configuration — avec paramètres de détourage accessibles.

Installation rapide

# Cloner le dépôt
git clone https://github.com/leblog92/fond_vert.git
cd fond_vert

# Installer les dépendances (Windows)
install.bat

# Lancer l'application
python main.py
